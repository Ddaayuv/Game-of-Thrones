مولّد بطاقات التهنئة بـ QR

أنشئ تهنئة مخصصة مع اسم المستلم والمرسل والرسالة والصور والموسيقى، ثم شاركها عبر رابط قصير أو رمز QR.

رابط قناة تيليگرام:
https://t.me/HardHso

تشغيل المشروع على Vercel:

1) اربط المستودع مع Vercel أو ارفع المشروع كما هو.
2) فعّل Vercel Blob وأنشئ Blob Store للمشروع.
3) تأكد من إضافة BLOB_READ_WRITE_TOKEN إلى Environment Variables.
4) أعد Deploy للمشروع.
5) افتح الموقع وأنشئ تهنئة.

الرابط الناتج يكون بالشكل:
https://YOUR-DOMAIN.vercel.app/g/Abc123xyz

ملاحظات:
- الروابط الناتجة قصيرة لأنها تستخدم مسار /g/ مع تخزين بيانات التهنئة في Vercel Blob.
- المتصفح قد يمنع التشغيل التلقائي للموسيقى بصوت مسموع، لذلك توجد أداة تشغيل داخل صفحة التهنئة مع محاولة تشغيل تلقائي عندما يسمح المتصفح.
- ملف index.html يحتوي واجهة الموقع كاملة، مع JavaScript وCSS داخل الملف نفسه.
