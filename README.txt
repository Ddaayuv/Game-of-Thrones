رفع المشروع إلى Vercel:

1) ارفع مجلد المشروع كما هو أو اربطه مع GitHub.
2) في Vercel فعّل Vercel Blob وأنشئ Blob Store للمشروع. سيُضاف BLOB_READ_WRITE_TOKEN تلقائياً إلى Environment Variables.
3) أعد Deploy للمشروع.
4) افتح الموقع وأنشئ تهنئة. الرابط سيكون بالشكل:
   https://YOUR-DOMAIN.vercel.app/g/Abc123xyz

مهم: المتصفح قد يمنع التشغيل التلقائي للموسيقى بصوت مسموع. لذلك توجد أداة تشغيل الموسيقى داخل صفحة التهنئة، مع محاولة تشغيل تلقائي عندما يسمح المتصفح.

المشروع يحافظ على واجهة index.html الأصلية ويضيف تخزيناً للبيانات والملفات حتى لا تصبح الروابط طويلة.
